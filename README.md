## 🌟 Tổng Quan Các Trang Của Website

Website được thiết kế gồm **4 phân trang chuyên nghiệp**, áp dụng hiệu ứng chuyển động mượt mà, đồ họa không gian 3D với **Three.js** và hệ thống phát nhạc nền tự động liên tục:

### 1. Trang Chủ (Tổng Quan) - `#/home`
- **Hero Section Công Nghệ Cao**: Không gian 3D tương tác với các hạt điện tử (particle constellation) và khối wireframe cơ điện tử xoay theo chuột.
- **Hình Đại Diện Đẳng Cấp**: Chân dung Võ Minh Kiệt với hiệu ứng ánh sáng neon, huy hiệu trạng thái sinh viên năm 4 chuẩn bị tốt nghiệp (T5/2027).
- **Mô Hình 3D Album Hình Ảnh (Three.js)**:
  - Tích hợp toàn bộ ảnh đời sống, bạn bè (chơi bida), chân dung kỷ niệm thành một **vòng xoay không gian 3D (3D Cylindrical Carousel)**.
  - Hỗ trợ cuộn chuột, kéo/thả chuột hoặc vuốt chạm để xoay mô hình 3D trong không gian thực.
  - Nhấp vào bất kỳ tấm ảnh 3D nào để mở cửa sổ phóng to (Lightbox) xem câu chuyện và thông số ảnh.
- **Thanh Chỉ Số Cốt Lõi**: 4 năm ĐH Lạc Hồng, Chứng chỉ CSWA SolidWorks, Thực tập Brother Sài Gòn, Chuẩn 3S-5S.
- **Bảng Năng Lực Cơ Điện Tử**: Phân cấp kỹ năng Thiết kế CAD, Nhúng STM32 và Quản lý nhà máy.

## 🚀 Hướng Dẫn Khởi Động Website

### Cách 1: Chạy nhanh bằng File Batch (Khuyên Dùng)
Chỉ cần nhấp đúp vào file:
👉 **`chay_website.bat`**  
Trình duyệt sẽ tự động mở trang web tại địa chỉ: `http://localhost:5173/`

### Cách 2: Chạy qua dòng lệnh Terminal
```bash
# Khởi động máy chủ dev (Vite):
npm run dev

# Hoặc mở trực tiếp bản Production:
npm run preview
```

### Cách 3: Chạy bản tĩnh đã đóng gói (Dist)
👉 Nhấp đúp vào file **`chay_ban_build_dist.bat`**  
Website sẽ chạy bản nén tối ưu tại: `http://localhost:8080/`
